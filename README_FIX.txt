LOADPILOT V5 — ВАЖНО

Эта версия специально сделана ОДНИМ index.html.
CSS и JavaScript находятся внутри index.html, поэтому на GitHub Pages
не будет проблемы, если папка assets не была загружена.

Как обновить:
1. Открой свой GitHub repository.
2. Удали старый index.html.
3. Загрузить НОВЫЙ index.html из этого архива в корень repository.
4. Commit changes.
5. Подожди 1–3 минуты.
6. Открой сайт с жёстким обновлением страницы.

Если старый assets/ уже есть, он для этой версии не нужен.

Важно: index.html должен лежать именно в корне репозитория, а не внутри папки loadpilot_v5.
