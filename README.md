# LoadPilot — Fridge Truck Planner

Веб-приложение для расчёта компактной загрузки холодильников в грузовую часть фуры.

## Файлы

- `index.html` — главная страница.
- `assets/style.css` — адаптивный дизайн.
- `assets/app.js` — логика приложения и Supabase.
- `supabase.sql` — таблицы и RLS-политики.
- `README.md` — эта инструкция.

## Запуск

Для GitHub Pages:
1. Создайте публичный репозиторий.
2. Загрузите все файлы с сохранением структуры папок.
3. Убедитесь, что `index.html` находится в корне.
4. Settings → Pages → Deploy from branch → `main` / root.
5. Откройте выданную GitHub Pages ссылку.

Для локального просмотра лучше использовать локальный web-server, потому что приложение подключает Supabase через ES module:
- VS Code + Live Server, или
- Python: `python -m http.server 8000`
- затем откройте `http://localhost:8000`

## Supabase

1. Создайте проект на https://supabase.com/
2. Откройте SQL Editor.
3. Вставьте содержимое `supabase.sql` и выполните.
4. Откройте Project Settings → API.
5. В LoadPilot откройте Настройки → Supabase синхронизация.
6. Введите Project URL и публичный anon/publishable key.
7. Зарегистрируйте аккаунт и войдите.

RLS-политики ограничивают записи текущим `auth.uid()`.

## Важно

Не вставляйте в клиентский код Supabase service_role key. Для браузера используется только публичный anon/publishable key.

## Текущая логика

- реальные пропорции холодильников;
- зазор 2 см;
- продольная и поперечная ориентация;
- несколько моделей одновременно;
- визуализация фуры;
- условная сетка палетов;
- сохранение локально;
- синхронизация каталога и настроек через Supabase;
- адаптивный интерфейс для телефона и компьютера.
